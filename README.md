# DataScience Snippets

Repositório de exemplos de diversos algoritmos de ML, dividos entre as principais classes existentes.

## Estrutura

Para facilidade de compreensão, cada variação do algoritmo está registrada em um notebook com células agrupando as seguintes etapas:

- Importação e configuração de dependências;
- Importação ou geração de dados;
- Wrangling dos dados a serem utilizados;
- Treinamento e parametrização dos modelos;
- Etapa de validação, bagging, boosting, etc;
- Demonstração dos resultados (ex: intercepto e coeficientes);
- Demonstração gráfica dos resultados e contraste com dados reais ou de validação;

## Informações Conceituais

Quando pertinente, os conceitos devem ser explicitados no cabeçalho do notebook ou em comentários no topo das células. Para auxílio do entendimento, uma pasta de imagens e outros artefatos pode ser referenciada dentro da pasta da classe do modelo.
